I installed some new Self-Hosted services that I like recently.
## Paperless - ngx

!![Image Description](/images/Pasted%20image%2020261014100033.png)

This is an self-hosted document manager that I host using a Docker Container I like it because it sorts out all my documents in a dashboard and I can easily search their titles , content and my more things.
[Paperless - ngx](https://docs.paperless-ngx.com/setup/)

## Calibre - Web

!![Image Description](/images/Pasted%20image%2020261014100335.png)

This is an ebook management software that works with the desktop app or the docker container Im using the app and this web container is hosted using docker and now I can read books on my laptop from my Tab or Phone and easily come back to where I left off , I didnt get much time to use it

[Calibre - Web](https://calibre-ebook.com/)
## Jellyfin Vue

!![Image Description](/images/Pasted%20image%2020261014100916.png)
This is an customizable version of Jellyfin that I installed that is fully customizable with .CSS files and looks very satisfying and It is so good looking. I use this to watch my movies and TV shows

[Jellyfin Vue](https://jellyfin.org/docs/general/clients/jellyfin-vue/)
